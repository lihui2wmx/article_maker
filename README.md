# article_maker

A repository-centric research and manuscript engineering system for AI-assisted scientific research.

The project is being bootstrapped. Its design goal is not one-shot paper generation: it will maintain auditable research state, evidence provenance, claims, experiments, manuscript artifacts, and human decisions so AI agents can assist with research, writing, review, and revision without taking final scientific authority away from the researcher.

See `PROJECT.md`, `AGENTS.md`, and `docs/ARCHITECTURE.md` as the project foundation is established.
